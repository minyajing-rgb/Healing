## Website placement model

### Home
Use Provence / Alishan / butterfly-garden imagery as visual story gateways rather than static decoration.

### Dynamic Map
Media appears in the right-hand **Story Rail** according to:
- selected place;
- selected era;
- modality;
- story relevance.

### Story pages
Video can expand inline, then offer:
- `Show this place on the map`
- `Move to this era`
- `Open related plant/object`

### Aroma & Apothecary Lab
Use perfume-lab and rare-ingredient clips for the interaction language:
`plant → harvest → preparation / extraction → object → story → evidence / safety`.

## Extracted visual rules

Keep:
- warm ivory;
- botanical illustration;
- elegant serif;
- thin gold ornament;
- large cinematic nature scenes;
- specimen-like side panels;
- maps, lifecycle and anatomy diagrams;
- apothecary/perfume laboratory tactility.

Upgrade:
- cleaner UI;
- more whitespace;
- translucent data glass;
- luminous lavender/cyan/gold route lines;
- subtle future-science overlays;
- interactive 3D specimens;
- map/timeline synchronization.

Avoid:
- visually dense faux-antique pages everywhere;
- generic occult-shop imagery;
- muddy colors;
- unlabeled magical effects presented as scientific evidence.
