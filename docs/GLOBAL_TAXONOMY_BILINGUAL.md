# Global Taxonomy / 全球疗愈双语分类

## Design principle / 设计原则

The taxonomy is **multi-axis**, not a single folder tree. A single item can belong to multiple axes.

Example / 示例:

**Lavender / 薰衣草**
- Material: Plant
- Modality: Aroma / Herbal / Bath
- Preparation: Essential oil / Infusion / Hydrosol
- Geography: Mediterranean + global cultivation
- Sense: Smell
- Evidence: multiple claim-specific records
- Safety: route-specific
- Timeline: historical + modern
- Map: origin/cultivation/use must be different location relationships

## Axis F — Sound/frequency distinction / 声音与“频率”分层

Do not collapse the following:

1. **Acoustics / 声学** — measurable frequency, amplitude, spectrum.
2. **Music / 音乐** — musical structure and listening/participation.
3. **Chant / 吟唱** — linguistic, respiratory, musical, ritual and social components.
4. **Vibroacoustic / 振动声学** — physical vibration delivered through sound/transducers.
5. **Binaural/entrainment products / 双耳节拍等** — product/intervention category.
6. **Metaphysical frequency / 灵性能量频率** — cultural/spiritual claim category; never silently converted into biomedical fact.

## Axis H — Evidence / 证据

### Traditional depth / 传统记录深度
- T0 — anecdotal / oral mention only
- T1 — one documented historical source
- T2 — multiple historical/ethnographic sources
- T3 — established living system with documented lineage/use

### Modern evidence / 现代证据
- E0 — not assessed / no usable evidence found
- E1 — laboratory/mechanistic/preclinical
- E2 — observational/qualitative/pilot
- E3 — controlled clinical study, limited certainty
- E4 — systematic review/meta-analysis or multiple controlled studies
- E5 — guideline/strong professional consensus for a specific indication

**The level attaches to a specific claim, not to an entire herb or tradition.**
