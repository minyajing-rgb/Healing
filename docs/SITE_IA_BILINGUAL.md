# Site IA & User Flow / 网站信息架构与用户流程

## Home / 首页

**Earth Healing / 地球疗愈**

Hero:
> Ancient wisdom, living traditions, modern evidence.  
> 古老智慧、活态传统与现代证据，在一张地球地图上相遇。

Primary entry buttons:
- Explore the World / 探索世界
- Explore by Method / 按疗愈方式
- Explore Timeline / 时间线
- Ask Earth Healing / 问 AI

Secondary portals:
Plants · Aroma · Water · Body · Food · Movement · Mind · Sound · Animals · Nature · Stone · Ritual · Energy · Time

## World / 世界地图

Default = clean 2D map; optional 3D globe.

Left filter:
- Method
- Tradition
- Era
- Evidence
- Safety
- Cultural access
- Media

Bottom timeline scrubber:
drag century/period → map updates.

Click a region:
- key traditions
- public plants/materials
- body/mind practices
- sound/ritual traditions
- baths/nature/animals
- sources
- related journeys

## Timeline / 时间线

Parallel tracks with “World / Region / Tradition / Modality” scopes.

Core actions:
- drag across time
- compare two regions
- open map for event
- open source
- show uncertainty/contested dating
- save journey

## Lab / 实验室

### Aroma Lab
plant → harvest → extraction/distillation → oil/hydrosol/resin → scent profile → tradition → evidence → safety

### Apothecary Lab
raw material → preparation type → vessel/tool → historical context → modern regulation

### Sound Lab
recording → waveform/spectrum → cultural context → participant practice → evidence → safety

### Plant Lab
3D anatomy → used part → distribution → preparation → chemistry/evidence links

## AI / Ask Earth Healing

- “Compare Yao bath, Japanese onsen and European balneotherapy.”
- “Show sound practices that involve chanting, but separate spiritual claims from clinical evidence.”

- bilingual response when requested
- sources visible
- claim type visible
- evidence visible
- safety visible
- uncertainty visible
