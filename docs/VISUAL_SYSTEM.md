# Visual System — Botanical Future Heritage / 植物未来遗产

## 1. Direction

The visual language combines the supplied Provence botanical-estate / field-atlas references and cinematic forest-healing references with a cleaner, more future-facing information system.

**Formula:**

`European botanical atlas + cinematic healing journey + museum specimen + future nature lab + luminous world map`

It should feel premium, calm, intelligent and alive.

---

## 2. What to keep from the references / 保留

- ivory / warm white editorial base
- elegant serif display titles
- botanical plates and specimen illustration
- thin ornamental gold linework
- generous nature photography / cinematic CG
- garden / estate / forest as explorable environments
- side-panel facts and structured labels
- map, anatomy and lifecycle mini-diagrams
- tactile apothecary / perfume / botanical-lab details

---

## 3. What to add for the future layer / 未来感升级

- large clean negative space
- translucent glass information cards
- luminous route lines and map nodes
- subtle spectral gradients: lavender → cyan → warm gold
- fine scientific-grid / coordinate overlays
- soft particle systems resembling pollen, breath, sound waves and constellations
- 3D botanical scans/specimens
- animated timeline rails
- holographic-but-minimal diagrams
- acoustic wave/spectrogram visualization
- evidence badges that feel like museum/science labels, not gamified scores

---

## 4. Avoid / 禁止方向

- dirty parchment everywhere
- muddy brown “ancient medicine” look
- horror/occult-shop witch aesthetic
- generic chakra rainbow as the universal healing symbol
- hospital-blue corporate UI
- overdecorated mystical symbols
- claiming a glowing aura visual is literal scientific evidence
- mixing anatomical facts and traditional body maps into one unlabeled layer

---

## 6. Typography

### Display
High-contrast editorial serif, elegant and botanical/museum-like.

### UI / data
Neutral modern sans-serif.

### Chinese
Use a refined Chinese serif for display and highly readable sans-serif for UI.

Do not commit font binaries to this repository unless licensing is explicitly cleared.

---

## 7. Core screen families

### A. Hero / 世界入口
Full-bleed cinematic landscape + minimal title + luminous map path.

### B. Atlas page / 图鉴页
Large specimen/scene on left; clean evidence/source/safety column on right.

### C. Map page / 地图页
Ivory/soft-dark switchable world map, glowing layer nodes, filter rail.

### D. Timeline page / 时间线
Horizontal/vertical cinematic timeline with map synchronisation.

### E. Plant specimen / 植物标本
Botanical illustration + macro photo + 3D + anatomy + preparation.

### F. Apothecary lab / 药师实验室
Raw material → preparation → vessel/tool → safety → source.

### G. Sound lab / 声音实验室
Waveform/spectrogram + culture/context + listening sample + evidence.

### H. Ritual context / 仪式语境
Documentary/editorial treatment, never fantasy-game UI by default.

### I. Compare / 对比
Museum-style split panels; same dimensions, no “winner.”

---

## 8. Image art direction

**Daylight knowledge mode:** bright natural light, cream-white, botanical color, precision labels.  
**Journey mode:** cinematic forest/garden/mountain/water; soft luminous trails.  
**Future lab mode:** glass, polished brass, translucent vessels, botanical samples, spectral light, clean counters.  
**Night mode:** deep green/charcoal with gold constellation-like paths; used sparingly.

---

## 9. Motif system

Primary motifs:
- leaf vein / 叶脉
- water ripple / 水纹
- sound wave / 声波
- root network / 根系
- constellation/network / 星网
- topographic contour / 地形线
- thin gold botanical filigree / 金色植物细线

These can morph into one another in motion design.

---

## 10. Bilingual composition

Default hierarchy:

```
中文主标题
English Subtitle
Local / Latin Name

中文摘要
English summary (collapsible on Chinese mode)
```

English mode reverses the hierarchy.
